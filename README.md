# Resilience 72

Preparado para las primeras 72 horas.

Base de una aplicación de preparación ciudadana para España, con atención inicial a Granada. El panel indica cuándo faltan datos oficiales.

## Desarrollo

Instala las dependencias con `npm ci`, arranca el servidor local con `npm run dev` y compila con `npm run build`. Usa `npm run preview` para servir la compilación.

La interfaz usa React, TypeScript y Vite. Las próximas fases incorporan herramientas locales, una PWA con Service Worker y, después, fuentes oficiales verificadas. Las convenciones están en `AGENTS.md`.
